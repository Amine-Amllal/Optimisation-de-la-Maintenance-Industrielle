### Architecture Notes

The Streamlit app imports directly from existing modules:
- `agent.py`: MaintenanceAgent class (PPO/DQN)
- `maintenance_env.py`: PredictiveMaintenanceEnv
- `config.py`: All hyperparameters
- `demo_mock.py`: StrategyResult dataclass

Model loading uses @st.cache_resource to prevent re-initialization:
```python
@st.cache_resource
def load_pretrained_model(algorithm: str, model_path: Optional[str] = None):
    agent = MaintenanceAgent(algorithm=algorithm, seed=config.RANDOM_SEED)
    if model_path:
        agent.load(model_path)
    return agent
```
